# Security

Found a security problem in the CommonGround plugin, the `commonground` command-line tool it
bundles, or the CommonGround service? Email **hello@commongroundapp.io** with "Security" in the
subject.

Say what you found, how to reproduce it, and which plugin version you are on
(`/commonground:status` shows it). Please do not open a public issue for a security problem.

We look into every report and reply to the person who sent it.

Everything else, bugs and questions included, is welcome in this repository's
[issues](https://github.com/serkanterek/commonground-plugin/issues).
